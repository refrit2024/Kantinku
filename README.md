## 🍽️ Tentang Unifood
**Unifood** adalah ekosistem digital kuliner hyper-local kampus closed-loop. Platform ini mengintegrasikan pemesanan pre-order kantin bebas antre lift, transparansi harga resmi stan tanpa markup terselubung, dan layanan pengantaran antar-ruang/antar-lantai oleh mitra kurir mahasiswa (Jastip).

### ✨ Fitur Utama
- **Katalog & Navigasi Kampus**: Informasi stan terverifikasi, jam operasional, foto hidangan otentik, dan menu andalan.
- **Transparansi Tarif Stan**: Perlindungan mahasiswa dengan jaminan tarif resmi stan dan kanal pelaporan selisih harga.
- **Jastip Antar-Lantai Kampus**: Pemesanan titip makanan antar lantai gedung kuliah oleh mahasiswa dengan ongkir transparan.
- **Portal Stan (Pedagang)**: Manajemen menu, stok harian, status ketersediaan, serta pencatatan pesanan real-time.
- **Portal Verifikasi & Admin**: Audit stan baru, monitoring keabsahan sertifikasi kampus, dan validasi wirausaha mahasiswa.

## 🚀 Menjalankan Proyek Secara Lokal

1. Clone repositori:
   ```bash
   git clone https://github.com/<username>/<repository-name>.git
   cd <repository-name>
   ```

2. Pasang dependensi:
   ```bash
   npm install
   ```

3. Jalankan server lokal:
   ```bash
   npm run dev
   ```

4. Bangun versi produksi:
   ```bash
   npm run build
   ```
